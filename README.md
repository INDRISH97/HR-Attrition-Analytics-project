# HR Attrition Analytics Project

## 📊 Project Overview

HR Attrition Analytics is an end-to-end data analytics project developed to analyze employee attrition, workforce demographics, compensation, job characteristics, employee satisfaction, and work-life balance.

The project uses **3,000 employee records** and demonstrates the complete analytics workflow from data cleaning and SQL analysis to Power BI dashboard development.

## 🎯 Project Objectives

- Analyze employee attrition patterns
- Calculate key HR performance indicators
- Identify attrition patterns across departments and job roles
- Analyze salary and compensation-related factors
- Study employee satisfaction and work-life balance
- Build an interactive HR analytics dashboard
- Generate business-focused HR insights
